# Grill Mistress District, build 1 (район любовницы Grill Dad)

Концепт утверждён Ivan 2026-11-15: стиль как у района отца Grill Dad, дом любовницы бирюзовый, квартира отдельно + телепорт у дома.
Генератор основан на генераторе района отца (палитра, кит, соседи, скалы), всё процедурное, внешних ассетов нет.

## Что в районе (500x500)
- Юг: арка SIZZLE AVENUE (надпись меняется в `gm_district.py`, функция `gate`), дорога к центру.
- Центр (x 170..330, y 170..330): площадь с плиткой, **бирюзовая 8-этажная башня** (корпус x 224..276, y 258..296, верх стен z=53),
  балконы с цветами и мини-грилями, навес, вывеска APARTMENTS над входом и большая на крыше.
  Крыша: гриль-терраса (настил, пергола, гирлянды, золотой гриль, зонтики, шезлонги, детский бассейн, фламинго). Декор, на крышу не попасть.
- **Телепорт** перед входом (250, 244): платформа с неоновым кольцом и аркой TELEPORT. Здесь якорь `ApartmentEntrance` (кнопка «Войти»),
  выход из квартиры возвращает на `ExitArrival` (250, 236). Сама башня закрытая (один твёрдый коллайдер), квартира — отдельная модель MistressFlat4.
- На площади: фонтан, BBQ-киоск с зонтиками, остановка с табличкой BUS, клумбы, скамейки, фонари, деревья.
- Север (x 170..330, y 354..500): BBQ-парк — фудтрак, столы с грилями, беседка, пруд с фонтаном, водопад в скалах.
- 10 соседских домов с закрытыми фасадами (цвета/крыши/пропсы другие, чем у района отца), заборы, общая линия забора между парами соседей.
- Коннекторы на 4 стороны (ConnectorN/S/E/W), водонапорная башня-гриль, билборд STEAL A DAD!.

## Порядок в Studio (только по команде Ivan)
1. File > Import 3D: `export/GrillMistressDistrict.fbx` (Upload выкл) -> Workspace.GrillMistressDistrict.
2. Command bar по очереди: `apply_gd_colors.luau`, `build_studio_colliders_anchors.luau`, `camera_block.luau`, `character_collision.luau`.
3. Квартира: см. `MistressFlat4_build1/README_RU.md` (нужны Anchors.ApartmentEntrance / ExitArrival из шага 2).
4. В конце `lighting_soft.luau` (Bloom только у неона, мягкий свет в квартире).
Важно: `apply_gd_colors` не запускать повторно после установки квартиры (он выключает CanCollide у всех мешей workspace).

## Координаты
План: x на восток, y на север, z вверх, 1 = 1 студ. В Roblox: X = -x, Y = z, Z = y (как у других районов).

## Пересборка
`blender -b --factory-startup --python source/build_gm.py -- <out>` (GD_NO_RENDER=1 без превью),
аудит `python source/audit_gm.py <out>` (numpy+scipy, venv `_inbox\GrillDad\.venv`),
коллайдеры `python source/gen_gm_colliders.py <out> <out>/scripts/build_studio_colliders_anchors.luau`.
Файлы района: `gm_district.py` (район), `gm_tower.py` (башня, площадь, телепорт), общий кит `gd_kit.py`, `gd_lib.py`, `gd_palette.py`.
