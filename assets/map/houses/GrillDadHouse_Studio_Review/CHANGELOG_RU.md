# GrillDadHouse — журнал изменений

## 2026-10-11 — первая полная сборка

- Создан процедурный билдер `build_grill_dad_house.py` по мастер-промпту (оболочка, интерьер, патио, гриль, сад, заборы).
- Исправлено по ходу проверки:
  - ложные срабатывания аудита защищённых зон: кирпичный цоколь у дверей разбит по пролётам, не одним объектом;
  - дверные косяки утоплены на 0,02, чтобы их внутренняя грань не совпадала со стеной (z-fighting);
  - газон вырезан булевой операцией под пол, дорожки и патио (нет копланарных поверхностей);
  - сосиска на гриле пересобрана из трёх кубов в настоящую изогнутую капсулу (одна, 0,55 × 0,14);
  - руки папы на детском рисунке соединены с телом наклонными полосами;
  - ракурсы Blender-превью гриля и семейной стены перенесены, добавлены кадры фото/фартуков.
- Импорт в чистое место Studio: 939 частей, 0 несовпавших имён; сохранено `.rbxlx`, затем `.rbxm`.
- Для скриншотов временно менялись `Lighting.ClockTime` (12, затем возврат 14,5) и прозрачность/тени крыши (возврат, 0 расхождений).
- Выполнена непрерывная ходьба аватара 25/25 этапов (QA-место).

Не вносилось: изменения в Dad-каталог, карту игры, Rojo, геймплейный код, прошлые дома.
