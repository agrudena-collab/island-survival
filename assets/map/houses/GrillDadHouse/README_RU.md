# GrillDadHouse — дом папы-гриль («Steal a Dad!»)

Рабочее название ассета. Не создаёт и не меняет персонажа Dad, редкости или каталог.

Просторное одноэтажное бунгало: скошенные передние углы, кремовые стены, кирпичный цоколь, графитовая
вальмовая крыша, кирпичный дымоход и задний патио с грилем, на котором папа жарит одну крошечную сосиску.

## Что лежит рядом

| Файл | Назначение |
|---|---|
| `build_grill_dad_house.py` | авторитетный процедурный билдер Blender (воспроизводим) |
| `GrillDadHouse.blend` | редактируемый исходник |
| `GrillDadHouse.fbx` | модульный экспорт (940 мешей, без камер/света/помощников) |
| `GrillDadHouse_Final.rbxm` | чистая модель ТОЛЬКО дома, pivot = логическая точка (0, 24, 0) |
| `apply_grill_dad_house_colors.luau` | цвета/материалы/якоря/коллизии для импортированного FBX |
| `manifest.json` | координатное соответствие, размеры, палитра sRGB, помощники, зоны, замеры |
| `component_registry.json` | реестр всех 940 компонентов (группа, материал, коллизия, bbox) |
| `DETAIL_CHECKLIST_RU.md` | чек-лист всех позиций спецификации |
| `walk_routes_qa.luau` | QA-скрипт непрерывной ходьбы аватара (запускается в Play) |
| `previews/` | рендеры Blender (фасад, патио, план, гриль, семейная стена, кухня, фото/фартуки) |

Ревью-пакет Studio: `../GrillDadHouse_Studio_Review/` (чистое место, QA-место, скриншоты, документы, ZIP).

## Как открыть и использовать

1. **Посмотреть место:** двойной клик по `GrillDadHouse_Studio_Review/GrillDadHouse_Final_Studio.rbxlx` или в Studio *File → Open from File*.
   Не подключайте Rojo к этому ревью-месту.
2. **Вставить модель в другое место:** *File → Import Roblox Model* и выбрать `GrillDadHouse_Final.rbxm`.
   Pivot модели — центр участка на высоте пола; положите `PivotTo(CFrame.new(x, groundY, z))`.
3. **Пересобрать из исходников:**
   ```
   blender -b --factory-startup --python build_grill_dad_house.py -- <папка_вывода>
   ```
   Затем импортируйте FBX (*Ctrl+M*, снять «Upload to Roblox») и выполните `apply_grill_dad_house_colors.luau` в командной строке Studio.
   Ожидаемо: `painted 940 parts (509 set non-colliding), 0 unmatched`.

## Координаты

Логические (X, D, H): X влево/вправо (лево отрицательное), D 0 фронт … 48 тыл, H высота над полом.
Blender (x, y, z) = (X, D − 24, H). После FBX: Roblox X = −x, Y = z, Z = y. При виде спереди логический +X справа.
Модель стоит pivot-ом в начале координат места: логическая точка (X, D, H) → Roblox (−X, H, D − 24).

## Ключевые размеры (измерено в импортированной геометрии)

- Участок 44×48; корпус 30×26 (X −15..15, D 4..30); стены 11,5 × 0,4.
- Крыша: свес X ±15,8, D 3..30,8, конёк H 16,4; дымоход 1,4×1,4 до H 17,6 (колпак 17,8).
- Обе двери: чистый проём **8,4 × 9,4**; створки открыты ~110° наружу, концы на |X| = 5,585.
- Зазор переднего забора **8,4**; задние выходы **8,0 + 8,0**; задняя полоса D 39,6..47,6 свободна.
- Гриль: 4,8×2,4, крышка открыта ~100°, сосиска ровно одна (0,55 × 0,14).

## Ограничения (честно)

- Перенос Dad и погоня семьи/NPC не проверялись: соответствующих систем в изолированной сцене нет.
- Меши MeshPart импортированы без загрузки на Roblox (локальные); на другом аккаунте/машине сверьте отображение.
- `CollisionFidelity` оставлен по умолчанию; точки коллизии мелких деталей отключены по правилу `NONCOLLIDE`.
- Studio по умолчанию отражает небо на SmoothPlastic: стены и пол могут выглядеть голубоватыми — значения Color совпадают с палитрой.
- Дом не вставлялся в карту игры и не подключался к Rojo (отдельная задача).
