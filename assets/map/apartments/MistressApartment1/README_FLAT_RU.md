# Квартира любовницы Regular Dad — детальная версия (2026-10-22)

Процедурная модель в Blender (не боксы: точённые ножки, лепнина, посуда, растения и т. д.), ≈155 тыс. треугольников, 43 чанка ≤ 9000, цвета вершин. Заменяет простую квартиру из `build_apartment.luau` (его внешняя часть уже заменена башней района `RegularDadDistrict`).

## Файлы
- `source/build_flat.py` — запуск, примитивы (`soft`, `hcyl`, `ring`, `wb`, стены с проёмами), сглаживание кривых ×1.8.
- `source/furn.py` — мебель и декор (стулья, круглый стол, чайный сервиз, диван, кресла, стеллажи, лампы, люстра, шторы, картины, зеркала, ковры, растения).
- `source/rooms.py` — планировка: пол/потолок/стены/плинтусы/наличники, скайлайн за окнами, холл, кухня с островом, столовая, гостиная, спальня, ванная, дополнительный декор.
- `source/export_flat.py` — чанки, `out/MistressFlat.fbx`, `out/flat.json`, рендеры `out/renders/*.png`.
- `studio_setup_flat.luau` — настройка в Studio после импорта FBX (см. заголовок).

Пересборка: `blender -b --factory-startup --python source\build_flat.py -- <абсолютный путь к out>`.

## Планировка (относительно начала квартиры; пол = y 1, потолок 11)
- Основная комната x −22…22, z −16…16: холл (ЮЗ, дверь выхода x −14), кухня у западной стены + остров с барными стульями, столовая в центре (круглый стол (2, −5), стул любовницы (2, −10.6)), гостиная (диван, кресло, журнальный столик, ТВ-стена, стеллаж), зона чтения у окна.
- Спальня x 23…46, z −16…3 (кровать, тумбы, шкаф, туалетный столик, скамья); ванная x 23…46, z 4…16 (двойная раковина, свободная ванна, душ, унитаз).
- Окно на север (скайлайн города), окно спальни, матовое окно ванной.

## Контракт со сервисами
`Interior.Arrival` (точка появления, смотрит на север), часть с тегом `ApartmentExit` (`ExitDoor`), часть с тегом `MistressDesk` и атрибутом `DadId = RegularDad` (`Table_Top`), `MistressSeat`, `GuestSeat`. Все числа и стиль — прототип на согласование.
