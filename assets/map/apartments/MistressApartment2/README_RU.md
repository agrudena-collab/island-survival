# MistressApartment2 — квартира любовницы Office Dad (первая версия, 2026-11-02)

Статус: генерация и аудиты готовы. В Studio: `studio_setup_flat.luau` запущен, квартира стоит в `MistressBuilding2/Interior`; в этом плейсе её origin (20000, -2000, 0), далеко вбок и под картой, чтобы её не было видно из района, проверена в Edit-режиме. `.rbxm` сохранён (`model/MistressApartment2.rbxm`), содержимое в чистом плейсе ещё не проверено. Ничего не закоммичено. Квартира придумана заново под стиль нашего биома Office Dad (не копия квартиры 1).

## Образ и планировка
Деловая опрятная студия. Палитра биома: голубо-серые стены, белые наличники и плинтусы, тёмно-синий акцент (стена с телевизором, изголовье), красный (диван, кресло любовницы, в тон красной башне), горчичный и бирюзовый, тёплый паркет, 3-тоновая плитка. Над всем панорамное окно на город с синими крышами.

Размеры (чистые), пол y = 1, потолок y = 12: основная студия x −24…24, z −17…17; спальня x 25…45, z −17…2; ванная x 25…45, z 3…17. Стены 1.0, двери 6–7 студ.
- **Прихожая (ЮЗ):** дверь выхода (синяя, на юге x −19…−13), консоль с зеркалом, лавка для обуви, крючки с пальто, подставка для зонтов, коврик у двери.
- **Кухня (З/СЗ):** Г-образная линейка (синие шкафы, мраморная столешница, плита с вытяжкой, мойка под окном, холодильник), остров с тремя барными стульями и подвесными лампами, полки, посуда, дорожка на плитке.
- **Рабочая зона (центр, у окна):** директорский стол 12×4.8 с двумя мониторами, лампой, бумагами, подставкой для ручек, рамками; её красное офисное кресло (спиной к окну), два стула для гостя, ковёр, кредензa под окном с декором, книжный шкаф, торшер, портфель.
- **Гостиная (ЮВ):** красный диван с кушеткой, журнальный столик, синее кресло, ТВ на тёмно-синей стене с панелями и полками, плед, корзина, растения, часы.
- **Спальня:** кровать с тёмно-синим стёганым изголовьем, тумбы с лампами, скамья, шкаф-купе, туалетный столик с зеркалом, ковёр, бра, плетёная корзина.
- **Ванная:** отдельно стоящая ванна, унитаз, душ с стеклянными панелями, двойная раковина с зеркалом, полотенечная лесенка, полка, коврик.
Окна: панорамное (север, гостиная/кабинет), спальни, кухни, матовое у ванной. **Вид из панорамного окна настоящий:** квартира на 10 этаже красной башни, окно смотрит на запад над районом (сквер с фонтаном, проспекты, кварталы с синими крышами, лес и горы вдали). Геометрию вида строит `source/view2.py` из `../../district/OfficeDadDistrict/out/skyline.json`, который пишет генератор района: сначала собрать район, потом квартиру (иначе вид пустой). Вид лежит вне комнат (≈139 тыс. трис, чанки по 150 студ), сама квартира ≈89 тыс.

## Контракт для сервисов (как у квартиры 1)
`flat.json`: `anchors` = `arrival` (−16, 1, 12.5, смотрит на север), `exit_door` (−16, 5, 17.4), `mistress_seat` (6, 4.2, −14.6, лицом к гостю), `guest_seat` (6, 3.55, −4.2), `table_top` (6, 4.1, −10). `studio_setup_flat.luau` создаёт `Interior` (Arrival, ExitDoor с тегом `ApartmentExit`, `Table_Top` с тегом `MistressDesk` и `DadId = OfficeDad`, MistressSeat, GuestSeat, коллайдеры, свет). Внешняя часть `MistressBuilding2/Exterior` (Entrance, ExitArrival) создаётся скриптом района `OfficeDadDistrict/studio_setup.luau`. ApartmentId назначает владелец.

## Сборка
```
blender -b --factory-startup --python source\build_flat2.py -- <абсолютный путь к out> [--norender] [--only=<кадр>]
```
Результат: `out/MistressFlat2.fbx`, `out/flat.json`, `out/audit.txt`, `out/renders/*.png`. Цифры: 228 279 треугольников всего (квартира ≈ 89 тыс. + вид из окна ≈ 139 тыс.; O 223.9 тыс., G 72, N 4.3 тыс.), 95 чанков ≤ 9000, 67 коллайдеров + круглые, 46 источников света.

## Studio
File → Import 3D → `out/MistressFlat2.fbx` (Upload to Roblox выключен), модель `Workspace.MistressFlat2`; ModuleScript с текстом `studio_setup_flat.luau`: `require(module)(<текст flat.json или URL>, <MistressBuilding2>, Vector3.new(ix, iy, iz))`. Место квартиры (в квартире 1 это (0, 600, 0)) выбирает владелец.

## Проверено (скриптами, `out/audit.txt`)
Пересечения коллайдеров, предметы вне комнат, висящие предметы и коллайдеры, мерцающие грани (совпадающие плоскости разных цветов у всех осевых боксов), блокировка дверей, достижимость (от Arrival до обоих стульев стола, кухни, гостиной, спальни, ванной, выхода: для агента R = 1.6 и для коридора 5 студ; у кровати проход 3.7 по замыслу), нормали замкнутых объектов, нулевые грани, NaN, потерянные вершины, лимит 9000, повторный импорт FBX (95 мешей, 228 279 трис): везде 0 замечаний. Добавлено 2026-11-03: **предметы не врезаются друг в друга и в стены** (объём каждого видимого предмета против коллайдеров соседей и стен), **нет невидимых стен** (коллайдер не выходит за видимые детали больше чем на 0.7 студа, у каждого коллайдера есть видимая геометрия), **нет твёрдых предметов без коллайдера**, **нет отрезанных карманов** (агент R = 1.0 доходит до всего свободного места), проходы в душ и в двери 3.6–7 студ.

## НЕ проверено
Вставка `.rbxm` в чистый плейс (счётчики после вставки), Play-тест (вход, диалог, выход), 3D-модель любовницы (на `MistressSeat` пока никого нет), несколько игроков в одной квартире.

Проверено в Studio (Edit): 92 меша, коллайдеры 67 + 17 круглых, 46 ламп, стёкла 0.55, теги `ApartmentExit` и `MistressDesk` (DadId = OfficeDad), `Arrival`/`MistressSeat`/`GuestSeat` на месте. `PathfindingService` успешен от `Arrival` до `ExitDoor` и `MistressSeat`. Стул гостя исправлен: коллайдер теперь спинка плюс блок сиденья до поверхности, `GuestSeat` лежит на верхней грани, а не внутри сплошного бокса. К стулу можно подойти спереди и с боков.
Вид из окна: пышные белые облака и пологие зелёные холмы вместо серых куполов (`source/view2.py`).
Вид из панорамного окна: район и горы видны (скриншот), `StreamingEnabled = true`.
