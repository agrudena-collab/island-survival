# MistressApartment2 — квартира любовницы Office Dad (первая версия, 2026-11-02)

Статус: генерация и аудиты готовы, Studio НЕ проверен. Ничего не закоммичено. Квартира придумана заново под стиль нашего биома Office Dad (не копия квартиры 1).

## Образ и планировка
Деловая опрятная студия. Палитра биома: голубо-серые стены, белые наличники и плинтусы, тёмно-синий акцент (стена с телевизором, изголовье), красный (диван, кресло любовницы, в тон красной башне), горчичный и бирюзовый, тёплый паркет, 3-тоновая плитка. Над всем панорамное окно на город с синими крышами.

Размеры (чистые), пол y = 1, потолок y = 12: основная студия x −24…24, z −17…17; спальня x 25…45, z −17…2; ванная x 25…45, z 3…17. Стены 1.0, двери 6–7 студ.
- **Прихожая (ЮЗ):** дверь выхода (синяя, на юге x −19…−13), консоль с зеркалом, лавка для обуви, крючки с пальто, подставка для зонтов, коврик у двери.
- **Кухня (З/СЗ):** Г-образная линейка (синие шкафы, мраморная столешница, плита с вытяжкой, мойка под окном, холодильник), остров с тремя барными стульями и подвесными лампами, полки, посуда, дорожка на плитке.
- **Рабочая зона (центр, у окна):** директорский стол 12×4.8 с двумя мониторами, лампой, бумагами, подставкой для ручек, рамками; её красное офисное кресло (спиной к окну), два стула для гостя, ковёр, кредензa под окном с декором, книжный шкаф, торшер, портфель.
- **Гостиная (ЮВ):** красный диван с кушеткой, журнальный столик, синее кресло, ТВ на тёмно-синей стене с панелями и полками, плед, корзина, растения, часы.
- **Спальня:** кровать с тёмно-синим стёганым изголовьем, тумбы с лампами, скамья, шкаф-купе, туалетный столик с зеркалом, ковёр, бра, плетёная корзина.
- **Ванная:** отдельно стоящая ванна, унитаз, душ с стеклянными панелями, двойная раковина с зеркалом, полотенечная лесенка, полка, коврик.
Окна: панорамное (север, гостиная/кабинет), спальни, кухни, матовое у ванной. За окнами город (кварталы с синими крышами) для вида, вне комнат.

## Контракт для сервисов (как у квартиры 1)
`flat.json`: `anchors` = `arrival` (−16, 1, 12.5, смотрит на север), `exit_door` (−16, 5, 17.4), `mistress_seat` (6, 4.2, −14.6, лицом к гостю), `guest_seat` (6, 3.55, −4.2), `table_top` (6, 4.1, −10). `studio_setup_flat.luau` создаёт `Interior` (Arrival, ExitDoor с тегом `ApartmentExit`, `Table_Top` с тегом `MistressDesk` и `DadId = OfficeDad`, MistressSeat, GuestSeat, коллайдеры, свет). Внешняя часть `MistressBuilding2/Exterior` (Entrance, ExitArrival) создаётся скриптом района `OfficeDadDistrict/studio_setup.luau`. ApartmentId назначает владелец.

## Сборка
```
blender -b --factory-startup --python source\build_flat2.py -- <абсолютный путь к out> [--norender] [--only=<кадр>]
```
Результат: `out/MistressFlat2.fbx`, `out/flat.json`, `out/audit.txt`, `out/renders/*.png`. Цифры: 89 021 треугольник (O 84.7 тыс., G 72, N 4.3 тыс.), 40 чанков ≤ 9000, 67 коллайдеров + круглые, 46 источников света.

## Studio
File → Import 3D → `out/MistressFlat2.fbx` (Upload to Roblox выключен), модель `Workspace.MistressFlat2`; ModuleScript с текстом `studio_setup_flat.luau`: `require(module)(<текст flat.json или URL>, <MistressBuilding2>, Vector3.new(ix, iy, iz))`. Место квартиры (в квартире 1 это (0, 600, 0)) выбирает владелец.

## Проверено (скриптами)
Пересечения коллайдеров, предметы вне комнат, висящие предметы и коллайдеры, мерцающие грани (совпадающие плоскости разных цветов у всех осевых боксов), блокировка дверей, достижимость (от Arrival до обоих стульев стола, кухни, гостиной, спальни, ванной, выхода: для агента R = 1.6 и для коридора 5 студ; у кровати проход 3.7 по замыслу), нормали замкнутых объектов, нулевые грани, NaN, потерянные вершины, лимит 9000, повторный импорт FBX (40 мешей, 89 021 трис): везде 0 замечаний.

## НЕ проверено
Импорт в Studio и запуск `studio_setup_flat.luau`, прозрачность стёкол и свет в Studio, путь `PathfindingService` от входа к столу, Play-тест (вход, диалог, выход), 3D-модель любовницы (на `MistressSeat` пока никого нет), несколько игроков в одной квартире.
