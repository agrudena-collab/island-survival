# Roadmap

1. Establish player profiles, safe loading/saving, and starting currency.
2. Define Dad catalog data and server-authoritative purchase/spawn flows.
3. Assign bases and display owned Dads with income generation.
4. Add stealing interactions, validation, and base protection rules.
5. Build client HUD, shop, prompts, and feedback from server state.
6. Add persistence, exploit-focused validation, and multiplayer playtesting.

Keep each step split into small, testable tasks before expanding gameplay scope.
